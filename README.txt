FOUR MONTHS WITH GAURI — QUICK GUIDE

Files:
- index.html: the website.

PREVIEW:
Open index.html in Chrome on your computer, or send it to your phone and open it in a browser.

PERSONALIZE:
- Open index.html in a text editor (VS Code / Notepad).
- Search for the letter text between “My Gauri, ❤️” and “Always your Deepu. 💗” and edit it to sound like you.
- The page has four photo frames. The current frames let you preview photos locally, but photos chosen this way do NOT become part of a published website. To make photos permanent, create a folder called “photos” next to index.html, add images (e.g. photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg), and replace each photo frame label block with:
  <div class="photo-slot"><img src="photos/photo1.jpg" alt="Our memory"></div>
  Repeat with photo2.jpg, photo3.jpg, photo4.jpg. Keep the image files in the photos folder when publishing.

PUBLISH FREE:
1. Sign in to GitHub and create a new public repository, e.g. four-months-for-gauri.
2. Upload index.html. If using photos, upload the photos folder and its images too.
3. In repository Settings → Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Wait for the published GitHub Pages link to appear. Open it on your phone and test it before sending it to Gauri.

Privacy note: anyone with the public link may be able to view the page and any photos you include. Only use photos you both feel comfortable sharing. Don't include private chats or personal information.
